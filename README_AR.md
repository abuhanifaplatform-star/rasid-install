# صفحة تثبيت تميّزي بسلوكي

1. فك الضغط وأنشئ مستودعًا مخصصًا في GitHub باسم `rasid-install`.
2. ارفع محتويات المجلد عبر `Add file → Upload files` أو `uploading an existing file` للمستودع الفارغ، ثم اضغط `Commit changes`. تأكد أن `index.html` ومجلد `icons` يظهران في جذر المستودع.
3. من `Settings → Pages` اختر `Deploy from a branch → main → / (root)` واضغط `Save`.
4. بعد النشر افتح `Visit site` على الجوال وثبّت الصفحة من Safari أو Chrome.
5. تأكد من ظهور شعار راصد واسم «تميّزي بسلوكي»، واضغط «فتح البرنامج» لاختبار رابط Apps Script. قد يفتح الرابط في المتصفح.
